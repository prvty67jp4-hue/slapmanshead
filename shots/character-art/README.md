# Character art pass: pictures

Made with `tools/capture_fighters.ps1` (on a copy of the save folder): the build before this pass in
`before/`, the build after in `after/`, side by side in `compare/`.

- `menu_<fighter>.png`: the main menu's fighter (ranger = Corvin Vale, huntress = Sable Rook,
  brawler = Bram "Anvil" Kask, striker = Ilya Fen).
- `loadout_<fighter>.png`: the loadout screen.
- `match_5m.png`, `match_15m.png`: all four in a match on the Courtyard, running with a katana, from 5 m and
  15 m (camera at eye height); `_steamdeck` versions on the Steam Deck preset at 1280x800.
- `bench_steamdeck.txt` (in before/ and after/): the Steam Deck preset timing run, 8 fighters.
- `accessories/<fighter>.png`: each accessory on its fighter's body, from tools/blender/build_accessories.py.
